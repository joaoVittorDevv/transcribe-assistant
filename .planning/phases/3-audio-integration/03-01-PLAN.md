<name>Task 1: Create audio_engine.py subprocess</name>
<files>app/audio_engine.py</files>
<read_first>app/audio_recorder.py</read_first>
<action>
Create `app/audio_engine.py` as a standalone subprocess entry point controlled by Electron via stdin/stdout JSON.

Implementation:
1. At module load, instantiate `AudioRecorder` with a callback that prints `{"type":"rms","value":0.75}` to stdout on each RMS update.
2. Run a `while True` loop reading JSON commands from stdin (newline-delimited). Accept:
   - `{"action":"start","mode":"mic"}` → call `recorder.start_recording("mic")` and print `{"type":"status","recording":true,"mode":"mic"}`
   - `{"action":"start","mode":"system"}` → same for system
   - `{"action":"stop"}` → call `recorder.stop_recording()`, print `{"type":"status","recording":false,"wav_path":"/tmp/xxx.wav"}`
3. On SIGTERM or EOF, clean up gracefully (stop recording if active, exit 0).
4. All stdout writes must be flushed (`sys.stdout.flush()`).
5. Make file executable: add `if __name__ == "__main__":` guard with the loop.

Reference the AudioRecorder API: `start_recording(mode: str)`, `stop_recording() -> Path`, callback `on_rms_update(rms: float)`.
</action>

1. Add a new module-level variable `let audioEngine: ChildProcess | null = null`.
2. Add `function startAudioEngine(): void` that spawns `uv run python app/audio_engine.py` in the project root directory, with `stdio: ['pipe', 'pipe', 'pipe']` (stdin, stdout, stderr). Set `detached: false`.

8. Ensure `stopServer()` and `stopAudioEngine()` are both called on quit.

The win reference must be accessible: store `const win = ...` in a module-level `let mainWindow: BrowserWindow | null = null` and assign before the `win.on('closed')` listener.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer -> localhost:18763 | Trusted internal FastAPI endpoint; CORS preflight handled by FastAPI config |
| main -> audio_engine stdin | Local subprocess; untrusted input from renderer is validated before forwarding |
| audio_engine stdout -> main | JSON from trusted Python process; parse with try/catch, ignore malformed lines |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-01 | Tampering | audio_engine stdin | mitigate | Validate JSON shape before passing to AudioRecorder; reject unknown action fields |
| T-3-02 | Denial of Service | POST /transcribe | accept | FastAPI enforces 100MB limit server-side; renderer-side file picker limits to audio files |
| T-3-03 | Information Disclosure | WAV temp files | mitigate | Temp files created with `delete=False`; FastAPI deletes on session cleanup (already implemented in server.py) |
| T-3-04 | Elevation of Privilege | IPC channels | mitigate | Only 'audio-command' and 'rms-update' exposed; audio-command accepts only {action, mode} — limited enum |
</threat_model>
