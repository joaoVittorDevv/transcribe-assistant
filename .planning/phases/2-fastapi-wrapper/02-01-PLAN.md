## SSE Helper
Create an async generator `transcription_events(audio_path, prompt_text, keywords, mode)` that:
1. Creates a `NetworkMonitor` (or reuses a shared one) to get `is_online_fn`.
2. Instantiates `Transcriber(is_online_fn)`.
3. Runs the blocking `transcriber.transcribe()` call in a background thread via `asyncio.to_thread()` so it does not block the event loop.
4. Within `on_chunk` callback: calls `await queue.put(chunk_text)` to send each chunk to the async generator.
5. On completion: `await queue.put(None)` to signal end.
6. Yields from the queue: `while True: chunk = await queue.get(); if chunk is None: break; yield {"event": "chunk", "data": chunk}`. Use FastAPI's `StreamingResponse` format with `event: chunk` and `data: <text>` fields — this maps to SSE `event: chunk\ndata: <text>\n\n`.

**Critical:** The `on_chunk` callback runs in the background thread, so it MUST use a thread-safe queue (`asyncio.Queue` with `put` from another thread). Use `asyncio.get_event_loop().call_soon_threadsafe(queue.put, chunk)` pattern to avoid event-loop confusion.

## Endpoints

### POST /transcribe
```
POST /transcribe
Content-Form: audio: UploadFile, session_id: str | None, prompt_text: str = "", keywords: str = "", mode: str = "auto"
```
- Accept file upload via `fastapi.UploadFile`.
- If `session_id` is provided and exists in `_active_sessions`, resume that session (per D-08).
- Create a new session entry in `_active_sessions` keyed by `session_id = str(uuid.uuid4())`.
- Initialize `db.initialize_db()` on startup (call once at module load).
- Spawn `asyncio.to_thread(transcriber.transcribe, audio_path, prompt_text, keywords_list, mode, on_chunk=chunk_callback)`.
- Return `StreamingResponse(transcription_events(...), media_type="text/event-stream")`.
- **Per D-06 + D-07:** The reconnection logic belongs to the Electron frontend. The server is stateless; it just streams chunks. If the client disconnects, the server-side generator is cancelled by FastAPI automatically.

### GET /transcribe/status/{session_id}
```
GET /transcribe/status/{session_id}
```
- Return the current accumulated text and status for a session.
- Response: `TranscriptionStatusResponse`. If session not found, raise 404.

### DELETE /transcribe/{session_id}
```
DELETE /transcribe/{session_id}
```
- Cancel an active session by removing it from `_active_sessions`.
- The background thread will continue running (killed via its own cancellation check — per Whisper task below).
- Response: `CancelResponse`.

```python
def _transcribe_whisper(self, audio_path: Path, keywords: list[str], on_chunk: callable = None) -> str:
    model = self._get_whisper_model()
    initial_prompt = ", ".join(keywords) if keywords else None
    try:
        segments, _ = model.transcribe(
            str(audio_path),
            initial_prompt=initial_prompt,
            language="pt",
            beam_size=5,
            vad_filter=True,
        )
        self._last_was_stream = False
        full_text = " ".join(seg.text.strip() for seg in segments).strip()
        # Emit chunks for each segment for consistency with Gemini streaming
        if on_chunk:
            for seg in segments:
                if seg.text.strip():
                    on_chunk(seg.text.strip() + " ")
        return full_text
    ...
```
This means Whisper segments come in one by one as chunks, mimicking Gemini's streaming behavior. This is a minimal change — no new return type, just adding the on_chunk call within the existing loop.

import asyncio
import pytest
from httpx import ASGITransport, AsyncClient
from app.server import app
from app.database import initialize_db

@pytest.fixture(autouse=True)
def setup_db():
    initialize_db()
    yield

@pytest.mark.asyncio
async def test_transcribe_endpoint_returns_sse_media_type():
    """POST /transcribe must return a StreamingResponse with text/event-stream."""
    async with AsyncClient(
        transport=ASGITransport(app=app), base_url="http://test"
    ) as client:
        # Create a minimal 1-second silent WAV (44.1kHz, 16-bit mono)
        import io, wave, struct
        buf = io.BytesIO()
        with wave.open(buf, "wb") as w:
            w.setnchannels(1); w.setsampwidth(2); w.setframerate(44100)
            w.writeframes(struct.pack("<h", 0) * 44100)  # 1 sec silence
        buf.seek(0)
        files = {"audio": ("test.wav", buf, "audio/wav")}
        data = {"session_id": "", "prompt_text": "", "keywords": "", "mode": "auto"}
        response = await client.post("/transcribe", files=files, data=data)
        assert response.status_code == 200
        assert "text/event-stream" in response.headers["content-type"]

@pytest.mark.asyncio
async def test_status_endpoint_returns_session_state():
    """GET /transcribe/status/{id} returns 404 for unknown session."""

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | Audio file upload | mitigate | FastAPI UploadFile reads are bounded; enforce max file size (e.g., 100MB) via `UploadFile` size check before passing to transcriber |
| T-02-02 | Denial of Service | Large audio file | mitigate | Limit upload to 100MB; timeout transcription via `GEMINI_TIMEOUT` config; asyncio.to_thread prevents blocking event loop |
| T-02-03 | Information Disclosure | Session ID enumeration | accept | Session IDs are UUIDv4; brute-force infeasible; same risk as existing session table |
| T-02-04 | Denial of Service | Rapid repeated POST /transcribe | mitigate | In-memory session dict is bounded; each session is a background thread with its own cancellation; rely on frontend throttling |
| T-02-05 | Repudiation | Missing audit trail | accept | Logging at key points (transcription start/chunk/DONE/ERROR); no external audit required for personal tool |
